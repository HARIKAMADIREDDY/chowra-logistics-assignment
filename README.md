# Chowra Logistics - Web Homepage

A modern, professional, and fully responsive logistics website homepage built with Flutter Web. This project was developed as a technical assignment to demonstrate clean UI/UX implementation, responsive design principles, and scalable code architecture.

## Features
* Fully Responsive Design: Adapts seamlessly to desktop, tablet, and mobile browsers using MediaQuery and flexible layouts.
* Modern UI/UX: Clean, corporate aesthetic utilizing a cohesive Navy Blue (#0A192F) and Orange (#FF6B00) color palette.
* Functional Components: Includes interactive frontend components like dropdowns, text fields, and elevated action buttons.
* Comprehensive Logistics Sections:
  * Dynamic Hero Section with a "Track Shipment" overlay
  * Responsive Services Grid (Domestic, Express, E-commerce, Freight)
  * Global Network Coverage Statistics
  * Interactive Rate Calculator & Quick Quote Form
  * "Why Choose Us" & Partner highlights

## Tech Stack
* Framework: Flutter (Web)
* Language: Dart
* Design System: Material Design

## Architecture & Code Quality
The codebase is structured using a simplified Clean Architecture approach to ensure maintainability and readability:
* core/theme/: Centralized configuration for all app colors, fonts, and global themes.
* presentation/pages/: Main screen assembly keeping the top-level widget extremely readable.
* presentation/widgets/: Modularized, single-responsibility UI components (Header, Footer, Hero, Services, etc.) for easy debugging and team collaboration.
